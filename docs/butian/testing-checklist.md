# 第一阶段测试清单

## 主流程

- [ ] 首次打开能看到欢迎引导。
- [ ] 点击“开始观星”后能看到星空。
- [ ] 点击中国、西方、叠合可以改变连线和标签。
- [ ] 点击星点能打开星官卡。
- [ ] 点击“选它来测量”能打开测量面板。
- [ ] 点击“记入奏折”能生成最近一次观测记录。
- [ ] 点击“下载奏折”能生成 SVG 文件。

## 移动端

- [ ] 360px 宽度下没有横向滚动。
- [ ] 主要按钮可以单手点击。
- [ ] 测量面板不会被屏幕底部遮挡。
- [ ] 关闭动效后主流程仍可完成。

## 内容边界

- [ ] 页面明确显示星位“按真实时刻与地点计算”。
- [ ] 页面明确显示“教学近似值：J2000 历元，未含岁差与折射修正”。
- [ ] 发布前校对二十八宿距星赤经表，并接入经过许可核验的正式星表。
