# 开发决策记录

## 2026-10-03：先做无依赖静态预览

原因：当前环境访问 npm registry 超时。为了让项目负责人马上看到和操作原型，先提供可直接打开的 `index.html` 静态预览；React/Vite 源码保留，网络恢复后再执行正式构建。

影响：

- 静态预览可以双击打开；
- 当前数据和读数是演示数据；
- React 源码与静态预览暂时存在两份实现；
- 正式版本需要把验证后的交互统一回 React 源码。

## 2026-10-03：第一版不承诺专业测量精度

原因：宿度、去极度、岁差和历元处理需要进一步校验。当前目标是验证用户是否理解“两套坐标描述同一片天空”。

## 2026-10-03：第一版不引入账号和后端

原因：核心体验不依赖云端保存。浏览器本地存储足以支持最近一次记录。

## 2026-10-06：引入真实天文计算，替换伪随机读数

决策：新增 `src/lib/astro.ts`——IAU 1982 平恒星时、赤道→地平坐标变换、天穹俯视投影（天顶居中、北在上、东在左）、二十八宿距星表与入宿度换算、去极度 = 90° − 赤纬。星点坐标改用手工整理的 J2000 标准值（参宿七星 + 北斗七星），界面星位随时间滑块与观测地点实时重算，未升起的星贴在地平圈外缘弱化显示。

影响：

- 测量面板与奏折读数从伪随机数升级为真实换算；
- 教学精度口径：J2000 历元，不做岁差归算与大气折射修正，古度（365.25）与今度（360°）不换算；
- 二十八宿距星赤经为手工整理近似值（正式版本需逐宿校对）；觜宿在 J2000 呈"负宽度"（觜参之辩），按退化宿处理，其天区并入参宿；
- 检查链新增 `test:astro`（天文计算断言，锚点含 J2000 恒星时 18.697374h、北极星高度≈纬度、中天自洽）与 `test:render`（jsdom 挂载 React 版全链路渲染）。

## 2026-10-06：修正星官命名，星数补全

决策：按传统星名修正演示数据——γ Ori 由"参旗"改为参宿五、α Ori 由"天关"改为参宿四、β Ori 由"玉井"改为参宿七；补入参宿六（κ Ori）与摇光（η UMa），参宿七星、北斗七星齐备。中西连线拓扑差异化：中国式突出参宿腰带三星，西方式为猎户沙漏形。

原因：原命名为示意性误用；接入真实坐标后星名与星位须一一对应。

## 2026-10-06：检查脚本用 Node 类型剥离直接导入 .ts

原因：TypeScript 7（原生编译器）不再暴露 `ts.transpileModule` 等 JS API。检查脚本（astro-check、render-check）改用 Node 22 内置类型剥离直接 `import '../src/lib/*.ts'`，零转译依赖。附带经验：jsdom 中驱动 React 受控 input 需用原型原生 setter 赋值再派发 change 事件，否则被 React 的 value 劫持去重。

## 2026-10-06：接入 HYG 星表做背景星野（≤5.5 等 2,865 颗）

决策：下载 HYG Database v3.5（CC BY-SA 4.0），经 `scripts/build-starfield.mjs` 过滤生成 `src/data/starfield.ts`（星等 ≤5.5、J2000、赤经转度、剔除太阳、亮星在前）。星野圆点与交互星点走同一套天文计算管线，随时间/地点实时重排，只画地平线以上的星；此前的装饰性随机星点纹理（visuals.starfieldDataUri）从天穹撤下，绢纹肌理保留。

影响：

- 天穹从"14 颗星 + 假纹理"升级为"14 颗交互星 + 2,865 颗真星背景"；打包体积增至约 315KB（gzip 107KB）；
- 署名与许可登记于 `apps/butian/SOURCES.md`；原始 CSV 不入库（.gitignore），生成脚本可复现；
- astro-check 新增星表抽检（数量口径、坐标合法性、天狼星赤经、亮度排序）；render-check 新增星野渲染断言（数量、盘面边界、纹理已替换）；
- 创意文档中"≤6.5 等约 9000 颗"全量口径留待正式版分片加载，当前为 ≤5.5 等平衡移动端性能。

## 2026-10-06：与并行会话的协同口径

决策：另一开发会话同期在天穹 UI 上迭代（可拖准星测量、标签防叠压、今夜简报、绢纹/星野纹理、奏折钤印、今夜亮星）。双方以"检查链全绿"为合流门槛：本轮 HYG 星野整合保留其全部功能，仅以真星表替换其随机星野纹理；其改动若使任一检查变红，以先恢复绿色为准。

## 2026-10-06：接入二十八宿主官星表（27 宿 121 星）

决策：按常见口径手工整理各宿成员识别（距星居首），坐标由 `scripts/build-lodges.mjs` 从 HYG v3.5 提取，生成 `src/data/lodges.ts`；与核心星表合并后全天 145 颗交互星、28 宿全覆盖（参宿沿用核心表）。连线按成员顺序连折线（正式版应按传统星图线样逐宿校订）。

影响：

- 测天面板可对任意宿星给出真实入宿度/去极度，二十八宿坐标系首次"全周天可测"；
- 交叉校验断言：每宿距星赤经在 HYG 提取值与 astro.ts 手工宿表之间逐宿比对（容差 0.6°），两套独立整理互为印证；另加星名与 id 唯一性断言（曾分别抓出毕宿五重名与斗宿/北斗 id 冲突）；
- 已知取舍：翼宿取巨爵座代表星 4 颗（传统廿二星）、张宿/奎宿成员为常见口径子集，均待逐宿校对；
- 生成器支持 `ref:` 语法引用核心表已有星（毕宿五 α Tau 复用并行会话的条目，占序号、参与连线、不重复生成）。
