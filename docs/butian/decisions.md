# 开发决策记录

## 2026-10-09：触屏宿群点按展开（移动端无 hover 的星名兜底）

原因：宿名让位于宿度环后，宿群成员星名默认 hint（悬停展开）——触屏设备没有 hover，用户只能逐颗开星官卡看名字；且移动端窄屏连"参宿 等7星"组锚也被过滤，参宿成员成了"无名且不可展开"的死角。

决策：新增 revealedGroup 状态与 tapStar 分流——点按 hint 状态的宿群星（含参宿），首次点按展开整组星名（不开卡）；同宿已展开再点则照常选中开卡；点空白处收回；关闭卡片后组名保持亮显便于扫视。桌面 hover 行为不变。

影响：

- render-check 新增五步断言（首次点按不开卡/整组展开/再点选中/组名保持/空白收回），既有"点参宿四开卡"断言按 tapStar 语义改为点两次；真实浏览器巡检扩到 65 项（M16-M19 触屏四步）全绿；
- 排障过程顺带修了巡检脚本两个自身缺陷（`?.click() ?? fallback` 的空值合并会双击；选择器误把"碰撞降级 hint 的北斗天玑"当宿群星），并根治 CDP 脚本 Edge 残留问题（Node kill 只杀启动器，改 taskkill /T + PowerShell 按命令行匹配杀 + 收尾延迟清理）；
- 产品代码的交互缺口仅参宿一处，已随本决策统一语义修复。
