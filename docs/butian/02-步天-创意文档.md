## 一、愿景宣言

**做一座可以走进去的中国古代天文台——你不是在"查星官资料"，你是钦天监的学徒，今夜当值。**

西方有 88 星座，中国有三垣二十八宿、283 星官、1464 颗正星。
每个中国人都能认出猎户座，却几乎没人认出自己的"参宿"——尽管它们本是同一片天空。

《步天》把真实的星空装进浏览器：星星的位置按真实天文计算，随你所在的时间与地点流转；
同一片天，你可以用**中国星官**看，也可以用**西方星座**看；
你还可以亲手架起**浑仪**，像三千年来的每一个观天者那样，给一颗星量出它的宿度与去极度。

**看天，测天，记天，传天——四步走完中国古人认识宇宙的完整闭环。**

## 二、大胆创新点

### 决策 1：观测闭环——"看天→测天→记天→传天"叙事结构（最激进）

不做星空资料站，做**角色化体验**。用户以"钦天监学徒"身份进入，全站围绕一条行动线：

1. **看天**：黄昏入场（按当地真实日落计算入场时间氛围），星空随真实时间点亮；
2. **测天**：调出浑仪，瞄准任意一星，读出**入宿度 / 去极度**（中国古坐标），同屏换算现代赤经/赤纬——亲手体会"两种坐标说的是同一颗星"；
3. **记天**：把今晚测得的星写进一张"星图奏折"（自动排版的竖排报告：日期、地点、所测星、宿度）；
4. **传天**：奏折导出成图分享。

理由：闭环结构把零散的"看点"变成有目标的"玩法"，参考作品均只有"看"没有"测"，这是本项目最深的一层创新。

### 决策 2：中西双星空——"铜镜翻转"切换

点击一枚铜镜按钮，整个天穹做一次翻转动画：中国星官连线翻成西方星座连线
（参宿三颗星正对猎户腰带的那一刻，是全站的"顿悟瞬间"）。
支持**叠合模式**：两套连线半透明同屏，差异一目了然。

理由：对照产生认知冲突，认知冲突产生传播——"原来中国星官不是星座的翻译，是另一套完全不同的天空分区"。

### 决策 3：客星剧场——站在 1054 年的开封夜空下

内置"历史天象剧场"：时间拨回**至和元年（1054 年 7 月 4 日）**，天空按真实星历渲染，
金牛座旁亮起一颗白昼可见的"天关客星"——今天的蟹状星云。
《宋史·天文志》原文随星浮现。后续将扩展敦煌星图、哈雷彗星古记载等剧幕。

理由：把"天文史"变成可亲历的场景，是科普内容的情感放大器；"古记载 ↔ 现今天体"的对照无人做过。

### 决策 4：水运仪象台是全站的"时间引擎"

页面的时间流逝由苏颂水运仪象台的 3D 模型"驱动"：枢轮转动、天衡擒纵一声声"咔哒"，
每声对应页面时间走一刻。仪器可单独拆解（枢轮/天池/受水壶/擒纵机构），配《新仪象法要》原文。

理由：让装饰物承担功能叙事——时间不是进度条，是这台机器"打"出来的。

### 决策 5：二十八宿宿度环——地平圈上转动的"天尺"

地平圈上叠加二十八宿宿度刻环，随真实时间缓缓转动；任何天体升落，都可在环上读到它"入某宿"。
这枚环同时是后续"测天"玩法的坐标系教具。

## 三、用户体验叙事（打开第一分钟）

1. **0 秒**：黑场，一行小字浮现："至和元年五月乙丑，客星出天关东南——可数日不见而后见。"随即隐去。
2. **第 3 秒**：黄昏的海边观星台。天边最后一线晚霞（按当前真实日期与纬度计算）。远处传来更漏声。
3. **第 10 秒**：太阳落尽，星星依真实星等逐颗亮起。镜头缓缓上仰，银河浮现。
4. **第 20 秒**：右下角铜镜按钮微光呼吸。点击——天空翻转，星官连线变成星座连线。
   "参"变成了"猎户"，屏上出现一行注："参宿：三星在东方，曰参，白虎之宿。"
5. **第 35 秒**：按提示调出浑仪。拖动瞄准圈套住一颗亮星，读数刻度滚动：
   "入觜宿 0 度 30 分，去极 62 度 51 分 ｜ 赤经 5h32m，赤纬 -0°18′"。
6. **第 50 秒**：点击"记天"，一张竖排奏折生成，落款"钦天监学徒习测"。导出、分享。
7. **第 60 秒**：提示明日可来"客星剧场"——1054 年的那颗星在等你。

## 四、功能架构

### MVP（3 周）
| 模块 | 内容 |
|------|------|
| 真实星空 | HYG 星表（约 9000 颗肉眼级）；J2000→地平坐标实时变换；时间/经纬度设置 |
| 中西图层 | 283 中国星官连线与名称；88 西方星座连线；独立/叠合/铜镜翻转切换 |
| 宿度环 | 地平圈二十八宿刻环，随时间转动 |
| 浑仪测星 | 简化浑仪瞄准交互 + 宿度/去极度 ↔ 赤经/赤纬实时换算 |
| 记天 | 奏折生成与图片导出 |
| 星官卡 | 点击星官：《步天歌》节选 + 含义 + 正星数 |

### V2（+2~3 周）
- 客星剧场第一幕（SN 1054）；
- 水运仪象台 3D 拆解与"时间引擎"动效；
- 太阳/月亮/行星视运动（五纬在星官间的实时位置）；
- "巡天任务"：按节气夜空布置观测清单（如"春夜找到大角"），完成盖印；
- 敦煌星图彩蛋（S.3326 公版扫描局部对照）。

## 五、视觉与声音方向

- **整体气质**：不是科幻感的太空，而是**古绢星图**——底色是深夜的"绀青/玄色"，星官连线是"泥金"，文字是竖排小楷；UI 借鉴古代星图版式（圆坛式分区、朱砂印章）。
- **两套天空的视觉语法**：中国星官用**折线+方框**（官名如"天关""天罴"浮于星旁，仿苏州石刻天文图）；西方星座用**柔白曲线+拉丁名小字**。翻转瞬间两套线稿做墨色晕染过渡。
- **浑仪**：程序化建模的铜色仪器，环上刻度按郭守敬简仪制式简化；读数用卷轴数字牌。
- **声音**：更漏滴答（时间引擎）、风声（随天色）、测星读数时的一声磬响。全部 Web Audio 合成或 CC0 采样。

## 九、传播策略

- **奏折卡**是传播物：竖排星图+测星记录+印章，古风出片；
- **"参 vs 猎户"对照图**是天然的知识传播点（一张图讲清"两套天空"）；
- 节点营销：流星雨/日食/行星合月等天象日前推"今晚这样看"专题（真实数据自动生成）；
- 预设标题：《我给每颗中国星星起了名字，然后亲手测了它》《1054 年那颗客星，我替你回去看了》。
