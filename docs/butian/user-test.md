# 第一轮真实用户试用脚本

## 测试说明

不要先解释产品。只告诉测试者：“请完成一次观星并保存你的记录。”

## 三个任务

1. 找到切换中国星官和西方星座的方法。
2. 选择一颗星并完成一次测量。
3. 保存或下载你的星图奏折。

## 记录指标

- 从打开页面到首次点击主按钮的时间；
- 是否看懂铜镜按钮的作用；
- 是否能找到星官信息卡；
- 是否能完成测量；
- 是否理解“教学近似值”；
- 是否愿意保存或分享奏折；
- 用户主动说出的第一句感受。

## 通过参考

- 30秒内开始观星；
- 2分钟内完成一次测量；
- 至少一半测试者能说出“参宿和猎户是在看同一片天空”；
- 没有人把读数明确当作专业观测结果；
- 至少一名测试者主动下载奏折。
