# 《步天》MVP 范围冻结

## 本轮目标

验证用户是否愿意完成一次“看天 → 切换命名 → 选星 → 教学测量 → 生成奏折”的完整体验。

## 本轮包含

- 参宿—猎户为核心对照；
- 北斗—大熊座作为辅助对照；
- 星点使用手工整理的 J2000 星表坐标（教学精度），星位随时间与地点实时计算；
- 入宿度、去极度、赤经、赤纬真实换算（不做岁差与折射修正）；
- 中国、西方、叠合三种模式；
- 简化测量面板；
- 奏折 SVG 下载；
- 本地保存最近一次记录；
- 移动端基础适配。

## 本轮不包含

- 全量9000颗星；
- 全量283星官；
- 三维水运仪象台；
- SN1054历史剧场；
- 账号、社区、支付、后端和外部API；
- 专业天文测量精度。

## 通过条件

新用户在不看额外说明的情况下，可以在30秒内完成一次切换，并在2分钟内生成一张奏折。
