# 整合路线图

> 文档编号：06 ｜ 状态：生效 ｜ 版本：v1.0（2026-10-06）
> 上位文档：[00-观象总纲.md](00-观象总纲.md)。
> 本文回答：整合按什么顺序做、每一步的验收条件、与各产品既有计划怎么交错。

---

## 一、总原则

1. **整合不阻塞产品。** 各产品的既有里程碑（今时第一轮试用、步天全量星官、
   璇玑外部验收与历法核验）按各自节奏推进，整合阶段为它们让路；
2. **每阶段有明确退出条件。** 未满足退出条件不进入下一阶段；
3. **随时可停。** 任一阶段停下，仓库都处于"三产品各自可运行"的健康状态。

---

## 二、阶段计划

### P0 · 文档统一（本次完成 ✅ 2026-10-06）

- 建立总纲层文档体系（00–06 + decisions）；
- 步天单项目文档归位 `docs/butian/`，smoke 检查同步更新并通过；
- 三产品代码零改动，各自检查链保持绿色。

**退出条件**：三应用检查链全绿（步天已验，今时/璇玑迁移前本就绿）；文档链接有效。

### P1 · 仓库归一（目录迁移）✅ 2026-10-06 完成

把三产品迁入 `apps/jinshi | butian | xuanji`，建立 npm workspaces 根。
详见 [02-技术整合方案.md](02-技术整合方案.md) 第四节迁移映射表。
执行记录见 [decisions.md](decisions.md) INT-009。

**前置**：璇玑桌面外部验收至少完成一轮目标机检查（避免迁移与验收互相干扰）；无硬性时间依赖。
**验收**：三应用在 monorepo 内各自完整验收链全绿；根 `verify:all` 跑通；
`启动璇玑.bat/ps1` 与 GitHub Pages workflow 路径同步更新并人工核对。

### P2 · 共享内核抽取

按"谁最痛先抽谁"（见 [03-共享内核规划.md](03-共享内核规划.md)）：

1. `@guanxiang/core`：先迁今时的 lunar/solar/moon/format（搬运为主），
   璇玑历法核验完成后把核验口径与样本灌入 core；
2. 今时率先改为消费 core（行为不变，读数一致）；
3. `@guanxiang/palette`：天色 token + 五行色引擎归一，三产品 CSS 逐步引用；
4. `@guanxiang/cardkit`：璇玑下载修复经验 + 今时分享实现合并，三卡换用。

**前置**：璇玑历法核验有结论（core 的正式口径依赖它）；今时第一轮试用完成（确认天色/签卡值得沉淀为公共资产）。
**验收**：core 单测 = 今时基准用例 + 璇玑核验样本全绿；三产品读数与抽取前逐项一致（回归对照表）；`verify:all` 全绿。

### P3 · 产品互链（观象档案）

实现 [01-产品整合与联动方案.md](01-产品整合与联动方案.md) 的 L2：

- 璇玑"我的底色"页新增"导出观象档案"；
- 步天新增档案导入 + 本命宿点亮（**三部曲标志性联动场景 S-01**）；
- 今时新增档案导入 + 生日节气标记（S-02）；
- 同时落地 L1（三产品"此刻"读数一致性）与 L3（三卡系列水印）。

**前置**：P2 完成（档案里的节气/星官数据必须来自 core 的核验口径）；
璇玑二十八宿口径考据有结论（natalMansion 字段的口径依据）。
**验收**：S-01 至 S-05 场景清单全部通过；无档案时三产品零报错（S-03）。

### P4 · 观象台壳（远期，不承诺）

璇玑 Electron 壳扩展为三殿入口；网页侧做观象台门户页。
**前置**：三产品均通过各自外部验收与真实用户试用；P3 运行稳定。
本阶段只保留方向，不排期、不承诺。

## 三、与各产品既有路线的交错

| 时段 | 今时 | 步天 | 璇玑 | 整合层 |
|---|---|---|---|---|
| 当前 | 邀请 3–5 人试用 | MVP 切片已验证 | 目标机验收 + 历法核验 + 真实用户 | P0 ✅ |
| P1 期间 | 依试用结论迭代（内容量决策） | 全量星官/星表接入开发 | 历法核验推进 | 目录迁移 |
| P2 期间 | 率先消费 core | 天文模块接入 core.sky | 核验口径灌入 core | 三包抽取 |
| P3 期间 | 档案导入 + 节气标记 | 本命宿点亮 | 档案导出 | 观象档案 |
| P4 及以后 | 全年模式等 V2 | 客星剧场、仪象台等 V2 | 日志深化、安装包 | 三殿壳（方向） |

规则：**冲突时产品线优先，整合层顺延**；每次产品里程碑复盘时同步评估整合层是否该推进。
