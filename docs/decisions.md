## INT-011 · 2026-10-09：P2 共享内核 @guanxiang/core 落地（四模块上收）

决策：按 docs/07-P2共享内核盘点.md 的边界与顺序，把 format/cities/solar/sidereal 四个低中风险模块上收到 `packages/core`（TS 源经 package exports 直发，步天/今时以门面 re-export 保持既有 import 路径与数值锚点不变）：sidereal=步天引擎（GMST/地平坐标/天穹投影/升起时刻），solar=今时 NOAA 太阳与月相，cities=城市表合并（北京/上海/广州取步天四位精度，成都/乌鲁木齐沿用今时），format=度分秒/方位格式化。步天 astro.ts 与今时 astronomy.ts/data.ts 变兼容门面；二十八宿表、入宿度、tonightAt 等产品语义留在各应用。璇玑按盘点决策暂不接代码，仅声明依赖。

影响：

- P2 验收达成：core 可被三应用解析；四模块迁移完成；三链 + verify:all 全绿且步天全部数值锚点（GMST 18.697374h 等）原样通过；宿名跨应用断言继续生效。lodges/terms 两模块按计划留待璇玑历法核验。
- 工程修正：npm 无 `workspace:` 协议（pnpm/yarn 专属），依赖声明用 `*` 由 npm workspace 自动链接；删除 apps/butian、apps/jinshi 的过时子 lockfile；CI 安装改为仓库根统一安装（否则 registry 上找不到 @guanxiang/core）。
- CI 落地实况（经四轮收敛）：Windows 生成的 lockfile 只含 win32 平台二进制，linux runner 上 npm ci/install 均不补装（npm/cli#4828）。解法=typescript 的 linux 二进制以 optional 条目手工补进 lockfile；rolldown/lightningcss 的 linux binding 在 CI 里按主包实际版本 `npm install --no-save` 显式补装。任何新原生依赖（含平台 optionalDependencies 的包）在 CI 首次部署时都可能再踩此坑，按同模式补。
- 后续：今时第一轮试用、璇玑历法核验完成后，做 lodges/terms 上收与璇玑 .js 产物接入（P2 完全体）。

## INT-001：采用"联邦式"整合，不合并产品

- 日期：2026-10-06
- 决策：三项目保持独立可运行、独立发布、独立版本；整合层只做文档统一、
  仓库归一、共享内核与可选联动。
- 原因：三个产品均已独立验证各自闭环；合并成单产品会破坏已验证的主线，
  且三者形态差异大（网页/PWA/桌面）。
- 代价：三份依赖与配置短期并存；共享只能渐进抽取。

## INT-002：系列命名为「观象 · 天时人三部曲」

- 日期：2026-10-06
- 决策：系列总名"观象"，三部分别为《今时·中国时间》（时）、《步天》（天）、
  《璇玑·数字观象台》（人）；题眼取《周易·贲·彖》"观乎天文，以察时变；观乎人文，以化成天下"。
- 原因：璇玑副标题已是"数字观象台"，三作主题天然构成"天—时—人"；
  "观象"一词同时覆盖观星、授时、知人三个古代职能，出处正统。
- 备注：对外品牌展示为"观象系列"；仓库根目录名暂不改（见 INT-007）。

## INT-003：P0 只整合文档，不动代码

- 日期：2026-10-06
- 决策：本次整合仅建立总纲层文档并把步天单项目文档归位 `docs/butian/`；
  三产品代码零改动（`scripts/smoke-check.mjs` 的两处路径引用除外）。
- 原因：三产品检查链均已绿色，先用文档对齐认知，再动结构；降低一次变更的风险面。
- 验证：步天 `test:smoke` 迁移后通过。

## INT-004：共享包零框架依赖

- 日期：2026-10-06
- 决策：`packages/*` 只允许纯 TypeScript 与浏览器标准 API，禁止依赖
  react / electron / vite 插件。
- 原因：今时（无框架）、步天（React）、璇玑（原生 JS + Electron）三类宿主
  必须能共用同一份内核。
- 代价：共享包实现须克制，宿主相关的策略留在应用层。

## INT-005：跨产品互通只用本地"观象档案"，不建后端

- 日期：2026-10-06
- 决策：产品间数据互通采用显式导出/导入的本地 JSON（观象档案 v1，
  见 01 文档第三节）；不建账号、云同步与任何网络通道。
- 原因：延续三项目"无后端、本地优先"的既定共识；观象日志等隐私数据不跨产品流动。
- 代价：跨产品体验需用户手动搬一次文件。

## INT-007：仓库目录名与产品目录名暂不改

- 日期：2026-10-06
- 决策：当前目录结构（根为步天、子目录 `今时中国/`、`璇玑/`）维持到 P1；
