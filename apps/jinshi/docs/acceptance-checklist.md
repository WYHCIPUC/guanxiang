## 需要项目负责人手动确认

- [ ] 本地开发地址可以打开首页。
- [ ] 手机触摸拖动可以改变时间位置。
- [ ] 电脑鼠标拖动可以改变时间位置。
- [ ] 键盘左右方向键可以移动15分钟。
- [ ] “回到此刻”可以回到当前时间。
- [ ] 取签卡片可以打开、关闭、复制和下载。
- [ ] 系统分享不可用时仍有下载和复制入口。
- [ ] 切换城市后页面提示发生变化。
- [ ] 真太阳时模式明确显示“近似修正”。
- [ ] 长卷上会显示当前城市的日出和日落位置。
- [ ] 拖动到日出、日落附近时，场景阶段会随计算出的时间切换。
- [ ] 时间信息中会显示一个月相标签。
- [ ] 时间信息中会显示农历日期和当前节气名称。
- [ ] 候应标签显示“候应”字样，用户不会误解为当前地区的实况预报。
- [ ] 节气库缺失时，基础时间仍然可以显示。
- [ ] 页脚会显示距离下一节气的近似倒计时。
- [ ] 声音只有在用户主动打开后才播放。
- [ ] 开启减少动画后，页面没有持续移动或闪烁。
- [ ] 375px宽度手机上按钮没有重叠。
- [ ] 1440px宽度电脑上长卷和按钮布局正常。
- [ ] 断网后已加载页面仍能显示基础界面。
- [ ] 来源说明没有把花信演绎写成历史事实。
