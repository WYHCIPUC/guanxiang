# 第一轮试用记录

这份表用于邀请 3—5 位体验者试用当前原型。不要先解释产品，先观察他们能否自己完成操作。

## 每位体验者的任务

1. 打开页面后，用自己的方式找到“现在”。
2. 找到黄昏，再回到此刻。
3. 生成一张“此刻签”。
4. 切换一个城市，观察页面有什么变化。

## 只问这三个问题

- 你刚才第一眼认为这个页面是做什么的？
- 哪一步让你不知道该怎么继续？
- 你愿不愿意明天再打开一次？为什么？

## 通过条件

- 至少4人能在30秒内理解当前时间位置。
- 至少4人能独立生成签卡。
- 至少3人能说出“它和普通时钟的不同”。
- 至少2人愿意第二天再打开。

如果不满足，下一轮只修复最大理解障碍，不增加新功能。
