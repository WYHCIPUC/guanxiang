# 项目负责人运行手册

## 第一次启动

1. 安装 Node.js 18 或更高版本。
2. 打开项目文件夹 `D:\今时中国时间`。
3. 在文件夹空白处右键打开终端。
4. 输入 `npm install`，等待依赖安装完成。
5. 输入 `npm run dev`。
6. 复制终端显示的本地地址，用浏览器打开。

`npm install` 只是在本地下载项目需要的开发工具和历法库，不会上传用户文件。

## 每次修改后的检查

```text
npm test
npm run check-release
```

第一条检查时间和历法计算。第二条会重新测试、构建，并检查发布文件是否完整。
发布前的 `check-release` 还会运行界面冒烟检查，确认主要入口能响应。

## 生成可部署文件

运行 `npm run build` 后，项目会生成 `dist/` 文件夹。部署时上传 `dist/` 内的内容，不要上传 `node_modules/`。

## GitHub Pages 部署思路

1. 创建一个 GitHub 仓库。
2. 把项目文件上传到仓库。
3. 在仓库设置中打开 Pages。
4. 选择构建后的静态目录，或使用 GitHub Actions 执行 `npm run build` 后发布 `dist/`。
5. 发布后打开网址，依次检查首页、取签、设置和来源页。

## 常见问题

### 页面空白

- 先确认是否直接双击了源码目录的 `index.html`。
- 应改用 `npm run dev` 后打开终端显示的地址。
- 如果是部署后空白，检查静态资源是否使用相对路径。

### 依赖安装失败

- 先确认电脑可以访问 npm registry。
- 再重新运行 `npm install`。
- 如果网络限制导致失败，只更换可信的 npm 镜像，不要下载来源不明的安装包。

### 页面卡顿

- 先在设置中打开“减少动画”。
- 检查是否同时打开了多个浏览器标签。
- 不要先增加图片、粒子或音频素材，先记录设备和浏览器版本。

### 内容需要修改

- 时间算法放在 `src/systems/`。
- 文化内容放在 `src/content/`。
- 颜色和布局放在 `src/styles.css`。
- 修改文化内容后，更新 `src/content/sources.json` 和 `CHANGELOG.md`。
