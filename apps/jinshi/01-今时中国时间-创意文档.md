# 《今时·中国时间》创意文档

> 项目编号：01 ｜ 状态：立项 ｜ 版本：v1.0（2026-10-03）
> 类型：实时交互网站 ｜ 形态：纯静态前端，可部署 GitHub Pages

---

## 一、愿景宣言

**不做一个显示时间的页面，而做一栋可以住进去的"时间之屋"。**

现代人活在钟表的数字里，古人活在"辰、刻、更、点、候、气"的肌理里。
我们把这个网站做成一幅**正在呼吸的水墨长卷**——你打开它的那一刻，你就站在"此刻"：

- 现在是申时三刻，卷轴上的光线就是申时三刻的光；
- 现在是惊蛰第三候"鹰化为鸠"，卷轴上的桃花正开到第三分；
- 现在是二更天，卷轴尽头的更夫正敲着梆子走过。

**日活型产品的终极野心：让用户每天打开一次，不是为了查资料，而是为了"回来看看天色"。**

---

## 二、大胆创新点

### 决策 1：时间即空间——放弃钟表盘隐喻（最激进）

传统时间类产品都是"表盘+指针"或"卡片+数字"。本作**彻底放弃表盘**：
整站是一幅横向长卷，**横向滚动位置严格映射一天中的时刻**（0:00—24:00 等距铺开）。
打开页面时视口自动滑动定位到"此刻"的位置。用户向左拖是回到黎明，向右拖是走向子夜——
**你不是在"看"时间，你是在时间里"行走"。**

理由：空间隐喻比数字隐喻的感知强度高一个量级（人对"走了多远"的直觉远强于"过了几分钟"），
且这是全网时间类产品从未有过的形态。

### 决策 2：一切视觉由真实天文驱动，无一帧是贴图动画

- 卷轴天色：由**真太阳时 + 日出日落晨昏蒙影**实时计算插值，不是固定的渐变贴图；
- 月亮：按真实月相相位渲染（凸月亏月、位置随日期沿黄道移动）；
- 花信：二十四番花信风，当前"候"对应的花卉按**开花进度**渲染（惊蛰三候桃花，且只开在属于它的那几天）；
- 更点声：夜间每到一个更次，远处传来一声梆子与"××更——"的空灵人声（可关）。

理由：参考作品《星辰大海》证明了"真实数据驱动的视觉"的感染力；本作把它从星空移到日常的时间。

### 决策 3：节气交节"换季仪式"

用户恰好在交节时刻（精确到分钟）打开页面时，触发一次"换季转场"：
全卷墨色晕开，上一候的花落入流水，新候的花信从天而降。
平时则以一枚**倒计时印章**静静陈列："距冬至交节：3 日 12 时 08 分"。

理由：给日活一个"错过今天就没有了"的仪式性理由。

### 决策 4："此刻签"——一分钟做一张时间卡片

任意时刻点击"取签"，生成分享卡：当前时辰名、候名、花信、月相、一句对应的古典诗文
（如申时配"日至于悲泉，爰上羲和"），附当日节气印章。卡面配色由当下天色取色。
**分享即传播：每张卡片都是网站的一个入口。**

### 决策 5：真太阳时模式——把"地方时"还给用户

提供开关切换"北京时间 / 真太阳时"（按用户经纬度校正），让乌鲁木齐的用户看见自己真实的正午。
附一屏极简科普："你戴的表，为什么和太阳不一样"。

## 三、用户体验叙事（打开第一分钟）

1. **0 秒**：黑场，一滴墨在屏幕中央晕开，浮现卷名"今时"。
2. **第 3 秒**：长卷在眼前展开——自动快速滑动到"此刻"位置停下。用户看到的是此刻的天色：
   下午四点半的斜阳、当值的花信树、远山与近水。
3. **第 8 秒**：屏幕一角浮现信息，不是仪表盘，而是**竖排的木牌**：
   "乙巳年 · 九月初三 ｜ 申时三刻 ｜ 惊蛰 · 三候 鹰化为鸠"。
4. **第 20 秒**：用户忍不住向左拖动卷轴——晨雾里日出正从山后升起（那是今早 6:58 的位置）。
   拖动时天色、花影、鸟鸣随之流变。
5. **第 45 秒**：点击"取签"，得到一张申时签卡，保存/分享。
6. **第 60 秒**：页面右下角一枚小小的印章提示："距清明交节还有 12 天"——明天再来的钩子已经埋下。

## 四、功能架构

### MVP（2 周）
| 模块 | 内容 |
|------|------|
| 长卷场景 | 24 小时横向卷轴；晨昏天色（含晨昏蒙影三级）；日出日落位置 |
| 时间系统 | 时辰+刻+更点；农历日期；真太阳时/北京时间切换 |
| 历法数据 | 二十四节气精确交节时刻；七十二候；月相 |
| 花信风 | 七十二候对应花信渲染（开花进度随候内日期推进） |
| 取签 | 此刻签生成与图片导出 |
| 设置 | 定位（手动输入经纬度或城市）、声音开关 |

### V2（+2 周）
- 打更音效与"更夫走卷"角色；
- 交节"换季仪式"转场；
- 全年模式：长卷拉远变成"一年十二月的四季山水"（日→年双尺度缩放）；
- 节气物候卡片集（每候一卡，可收集）；
- PWA：可添加到主屏，成为手机"时间页"。

## 五、视觉与声音方向

- **配色**：随天色实时插值的"天色色板"——从黎明的"东方既白"到正午的"天缥"，从黄昏的"暮山紫"到子夜的"玄青"（全部采用中国传统色名）；近景山水用"墨分五色"。
- **字体**：标题用思源宋体/汇文明朝体；竖排木牌用书法体点缀。
- **动效**：一切动效为"呼吸感"——光线的移动是连续的，花是慢慢开的，没有弹跳与闪烁。
- **声音**：默认静音；开启后有三种环境音随天色切换（晨鸟/昼蝉/夜虫）与更点梆子。全站音量克制，"像一个安静的朋友"。

## 六、技术架构与数据来源

| 层 | 选型 |
|----|------|
| 构建 | Vite + TypeScript，无框架或 Svelte（轻） |
| 渲染 | Canvas 2D 视差长卷（远景山/中景水/近景花树三层视差） |
| 天文计算 | suncalc（日出日落晨昏）+ 自实现太阳时修正；lunar-javascript（农历/节气/月相） |
| 交节时刻 | 由寿星天文历算法（公开 C 代码）移植或预计算 2020—2050 交节表打包为 JSON |
| 音频 | Web Audio 合成（鸟鸣/虫鸣用振荡器+噪声，避免音频素材版权问题） |
| 部署 | 纯静态，GitHub Pages / Vercel |

**数据合规**：历法与天文均为公开算法；诗文来自公版古籍；无后端、无账号、无追踪。

## 八、风险与对策

| 风险 | 对策 |
|------|------|
| 天色插值在晨昏过渡处不够美 | 以中国传统色手工设计 12 个关键色标，算法只做关键帧间的优雅过渡 |
| 移动端 Canvas 性能 | 视差层数降级（移动 2 层）；离屏预渲染静态层 |
| 农历/节气算法边界错误（闰月、交节分钟级） | 采用久经考验的 lunar-javascript + 寿星历，并对 2020—2050 全量自测比对 |
| 用户新鲜感衰减 | 换季仪式 + 花信进度 + 物候收集制造"隔几天才有"的回访理由 |

## 九、传播策略

- **此刻签**是核心传播物：每张卡自带二维码，天色配色千人千面；
- 节点营销：每个节气当天发"交节海报"（自动生成），节气是天然的 24 次/年免费流量节点；
- 打"年轻人重新看见时间"的情绪角度投放小红书/B站（与参考视频同渠道）；
- 标题预设：《我把中国时间做成了一幅画》《你的申时三刻，长这样》。

## 十、一句话总结

**把时间从数字里放出来，让它在山水之间行走——每天打开一次，看看自己活在天道的哪一格。**
