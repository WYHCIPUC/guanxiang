# 更新记录

## 0.2.0 · 2026-10-03

- 增加鼠标/触摸拖动时间长卷。
- 增加键盘左右方向键，每次移动15分钟。
- 增加四个阶段的花信场景标签，并明确标记为产品化演绎。
- 增加用户主动开启的低音量环境声，默认关闭。
- 增加 Web App Manifest、图标和基础离线缓存。
- 增加第一轮用户试用记录模板。
- 增加相对资源路径，构建后的 `dist/` 可用于 GitHub Pages。
- 增加阶段切换提示，强化从一段时间走入另一段时间的仪式感。
- 增加一年总览和本地签卡收藏，数据只保存在当前浏览器。
- 增加按城市和日期计算的日出/日落标记与近似月相标签。
- 接入 MIT 许可的 `lunar-javascript`，显示农历日期和当前/下一节气。
- 接入七十二候传统名称，界面标注为候应与产品化文化内容。
- 昼夜与晨昏判断改为使用城市和日期的日出/日落近似结果，并增加一至五更标签。
- 增加距离下一节气的近似倒计时提示。
- 增加 Vitest 本地测试，覆盖时间边界、天文近似和历法解析。
- 增加统一来源登记文件和内容版权审查表。
- 增加基于 Happy DOM 的构建产物界面冒烟检查。

## 0.1.0 · 2026-10-03

- 建立24小时横向长卷原型。
- 增加时间定位、四种天色、城市预设、真太阳时近似切换和此刻签卡片。
