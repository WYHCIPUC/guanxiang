# 今时 · 中国时间

这是一个不依赖后端的静态前端原型，用一条 24 小时横向长卷表达中国传统时间。

## 启动

1. 安装 Node.js 18 或更高版本。
2. 在项目目录打开终端，运行 `npm install`。这会安装 Vite 和 TypeScript。
3. 运行 `npm run dev`，终端会显示一个本地地址，用浏览器打开它。

请不要直接双击源码目录中的 `index.html`。源码通过 Vite 加载 TypeScript 模块，直接使用 `file:///` 地址时浏览器会拦截模块路径。构建后可以打开 `dist/index.html`，或者始终使用 `npm run dev`。

## 构建检查

运行 `npm run build`。它会先检查 TypeScript，再生成可部署的 `dist/` 文件夹。

发布前可运行 `npm run check-release`，它会重新构建并检查关键发布文件是否存在。

`npm test` 会运行本地单元测试，覆盖时辰边界、日出日落顺序、月相范围和节气解析。

`npm run smoke-ui` 会在构建产物上检查首页、取签、一年总览、设置和来源入口。

内容来源和许可证记录在 `src/content/sources.json`，发布前的人工审查步骤记录在 `docs/content-review.md`。

## 当前原型范围

- 24 小时横向时间长卷
- 当前时间自动定位
- 黎明、白昼、黄昏、夜间四种状态
- 北京、上海、广州、成都、乌鲁木齐五个城市预设
- 北京时间 / 真太阳时的近似切换
- 此刻签卡片、复制、下载和系统分享
- 设置、来源和减少动画
- 可选环境声（用户主动打开）
- 基础 PWA 安装和离线缓存
- 一年总览（季节视觉预览）
- 本地签卡收藏（最多保留30张）
- 本地 MIT 许可的农历/节气计算库，用于显示农历日期和节气名称

第一版使用少量产品化表达，不能替代专业天文或历法工具。
