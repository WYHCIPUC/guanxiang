# 路线图完成状态

记录日期：2026-10-05。璇玑的主要交付形态已改为 Windows 优先的桌面客户端；网页版本是开发预览和备用体验。

## 阶段0：确认范围和素材

状态：完成（项目侧）

- 已冻结“输入—今日观象—日志—七日复盘”为第一版主线；总盘、五行、命纹和分享降为我的底色辅助入口。
- 已记录算法、内容、版权和隐私待核验项。
- 已明确不加入账号、后端、支付、社区和外部 API。
- 已登记桌面形态决策：Electron 开发 Alpha 先于安装包；Tauri 作为后续评估路线。

## 阶段1：视觉方向和可点击原型

状态：完成

- 首页、输入页、今日观象、日志、七日复盘、我的底色、详情页、分享卡和说明页可访问。
- 玄青夜景、金线、环形盘面和命纹视觉已落地。
- 网页预览和桌面窗口共用同一套页面代码。

## 阶段2：核心交互原型

状态：完成（网页预览和 Electron 开发机窗口）

- 输入、生成、今日记录、日志编辑/导入/导出/删除、七日复盘、拖拽旋转、详情下钻、返回、重新开始和本地保存已实现。
- 支持键盘入口、错误提示、分享弹窗焦点管理和减少动画设置。
- 桌面壳已固定 `xuanji://bundle/` 本地 origin，关闭 Node 集成并启用上下文隔离和沙箱；Electron 44.5.1 开发机窗口已完成一次真实启动、记录、复盘和重开恢复。

## 阶段3：MVP开发

状态：完成（原型口径）

- 三柱、五行、命纹、分享卡、说明与隐私页已实现。
- 支持 SVG 下载、观象日志 JSON 导出/导入和本地反馈 JSON 下载；日志条目可按日期编辑或删除。
- 正式历法核验尚未完成；星官、阴阳四维和生日节气仍是标注 V2 的试验切片。

## 阶段4：测试与修正

状态：项目侧自动检查和开发机桌面实机完成，目标电脑和真实用户待执行

- `npm run verify` 串联构建、桌面壳检查、方案检查、47 项核心烟测、发布检查和 HTTP 检查。
- 已有一次真实浏览器核心流程和 375px 布局记录；这只证明网页预览，不替代 Windows 桌面验收。
- 待完成另一台真实 Windows 电脑的离线、打印、下载和导入/导出检查，以及 3–5 名用户试用。

## 阶段5：部署和发布准备

状态：桌面 Alpha 准备完成，安装包未开始

- 已提供 Electron 主进程、空预加载脚本、固定本地协议和桌面静态检查。
- 已提供网页预览启动脚本和备用静态服务器。
- Electron 依赖已安装并通过开发机验证；尚未生成安装包、签名或配置更新服务。

## 阶段6：真实用户试用与迭代

状态：等待外部试用数据

- 反馈可以本地保存并由用户主动下载。
- 应先观察用户是否完成桌面核心闭环、是否理解文化边界、是否愿意保存/分享，再决定 V2 模块保留、隐藏或删除。

## 当前发布门槛

在另一台目标 Windows 电脑验收、真实用户试用和历法资料核验完成前，项目只能称为“Windows 桌面开发 Alpha”或“小范围体验”，不能宣称正式预测服务或正式历法工具。逐项证据见 [完成审计](completion-audit-2026-10-04.md) 和 [外部门槛状态](external-gate-status-2026-10-04.md)。
