# 发布准备说明

## 产品交付顺序

璇玑现在以 **Windows 优先的桌面客户端** 为主要产品形态。网页版本只承担开发预览、备用体验和静态内容检查，不把网页离线缓存当作桌面客户端的运行基础。桌面客户端的技术边界见 [桌面客户端形态修订](desktop-client-plan.md)。

当前桌面部分是 Electron 开发 Alpha：窗口、安全配置和固定本地协议已经写入仓库，但尚未安装 Electron 依赖、启动真实窗口或生成安装包。因此当前可以验收“桌面壳代码与安全约束”，不能把它写成“已发布安装程序”。

## 桌面开发启动

项目负责人确认安装 Electron 后，在项目根目录打开 PowerShell，执行：

```powershell
npm install --save-dev electron
npm run desktop:dev
```

第一条命令会下载 Electron 开发依赖，第二条命令会打开本地桌面窗口。窗口打开后，可以离线完成输入、总盘、详情、SVG 下载和打印。关闭窗口后不应留下本项目启动的 Node 服务进程。若安装尚未完成，先运行 `npm run desktop-check`，它只检查文件和安全配置，不会启动桌面窗口。

桌面 Alpha 的通过条件：

- [ ] Windows 窗口能在无网络时打开 `xuanji://bundle/index.html`。
- [ ] 窗口没有地址栏，页面不能跳到外部网站。
- [ ] 输入、总盘、详情、分享、打印和本地保存可用。
- [ ] 关闭并重新打开后，最近一次本地观盘仍可恢复。
- [ ] `npm run desktop-check` 和 `npm run verify` 通过。

## 网页开发预览

网页预览仍可用，优先双击项目根目录的 `启动璇玑.bat`，或在项目目录运行：

```powershell
npm start
```

然后打开 `http://127.0.0.1:4173/`。Node.js 是运行 JavaScript 的工具；没有 Node.js 时可退回：

```powershell
python -m http.server 4173 --directory D:\璇玑
```

网页版本的 Service Worker（浏览器离线缓存）只在 `http`/`https` 预览中注册，桌面端的 `xuanji://` 本地资源不注册它。

## 发布前检查

- [ ] 运行 `npm run verify`。它会检查网页构建、桌面壳、方案结构、核心烟测、发布文件和 HTTP 预览资源。
- [ ] 已安装 Electron 时，实际启动桌面窗口并执行 [桌面客户端验收清单](desktop-client-plan.md)；未安装时不得宣称桌面运行已通过。
- [ ] 在观象日志中导出 JSON，清空后用“导入备份”恢复；记录日期、行动镜头和正文与原来一致。
- [ ] 至少一台真实 Windows 电脑完成输入—观盘—详情—分享—重开恢复流程。
- [ ] 确认没有把姓名、生日、反馈或本地缓存文件上传到仓库。
- [ ] 确认字体、图片、音频和数据表都有来源记录。
- [ ] 确认首页、详情页和分享卡仍显示文化体验免责声明。
- [ ] 真实用户试用和历法资料核验完成前，只称“第一阶段原型”或“小范围体验”。

## 暂不发布的内容

安装包、代码签名、自动更新、托盘、账号、云同步、原生文件夹写入、远程日志和后台都不在当前 Alpha。Windows 安装包应在桌面窗口通过、真实用户试用完成、图标与版权确认后再做。

三柱、二十八宿和节气仍有待正式资料核验；公开试用时必须保留近似口径说明，不得宣传为正式排盘或预测服务。
