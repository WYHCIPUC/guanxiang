# 第一阶段验收检查

## 自动检查

在项目根目录运行：

```powershell
npm run verify
```

它依次检查网页构建、桌面壳静态安全约束、十四部分方案结构、核心烟测、发布文件和 HTTP 预览资源。`npm test` 当前包含 47 项核心烟测，并运行 Service Worker 行为模拟；模拟不能替代真实断网检查，也不代表桌面窗口已启动。

如果 Electron 已安装，再运行：

```powershell
npm run desktop:dev
```

如果 Electron 尚未安装，使用 `npm run desktop-check` 检查桌面文件，不要把它当作窗口运行证据。

最近一次开发机窗口验收记录见 [desktop-qa-2026-10-05.md](desktop-qa-2026-10-05.md)。这份记录证明开发机上的窗口和本地记录闭环已经实际运行过，不代表另一台电脑或安装包已经通过。

## 桌面客户端（主要验收对象）

- [ ] Windows 无网络时能打开桌面窗口并进入空盘首页；已有 profile 时直接进入今日观象。
- [ ] 窗口没有地址栏，不能在应用内打开任意外部网页。
- [ ] 点击“开始观盘”进入输入页；称呼可为空，公历生日必填。
- [ ] 不填生日时显示文字错误提示；示例按钮可直接生成结果并进入今日观象。
- [ ] 今日观象能选择五种行动镜头，填写一件事、精力、专注、心境和备注并保存。
- [ ] 保存后观象日志显示记录；按日期切换可以编辑，导出 JSON 后再导入不会重复增加。
- [ ] 日志记录能分别保存场景、事实、感受和下一步；两条不同日期的记录可以进入“记录对照”。
- [ ] 导入日志先显示新增、覆盖和跳过数量，取消确认不会改动本地数据。
- [ ] 单条删除前有确认，删除后 5 秒内可以撤销，超时或刷新后不再显示；没有记录时导出按钮给出提示。
- [ ] 七日复盘显示真实记录数、平均精力/专注、完成事项和连续记录天数。
- [ ] 我的底色能看到总盘、三柱摘要、主色和命纹。
- [ ] 总盘可用鼠标拖动；文字入口可替代盘钉操作。
- [ ] 命盘、五行、命纹详情可打开并返回底色。
- [ ] 分享弹窗可复制摘要、下载 SVG、打开打印预览；Escape 能关闭。
- [ ] 关闭窗口后重新打开，本地 profile 和日志仍能恢复。
- [ ] 说明页可清除观盘和反馈记录，清除后重新打开不再恢复。
- [ ] 系统开启“减少动画”后，结果仍完整可用且不持续旋转。
- [ ] 断网不会导致桌面页面依赖远程资源；本地 SVG 下载仍由用户主动触发。

## 网页预览（辅助验收）

- [ ] `npm start` 后打开 `http://127.0.0.1:4173/` 能看到空盘首页。
- [ ] 手机宽度约 375px 没有横向滚动，电脑宽度约 1280px 文字和盘面清晰。
- [ ] 在本地服务器环境下载 SVG 和反馈 JSON，文件不是空文件。
- [ ] 若要验收浏览器离线，运行 `npm run edge-offline-check`；只有输出 `PASS` 才记为真实浏览器通过，`UNVERIFIED` 只能记为未验证。

## 内容、隐私和无障碍

- [ ] 三柱、五行、星官和节气页面明确标出近似、试验或产品化演绎口径。
- [ ] 任何外部数据、图片、字体、音频和古籍解释都有来源、版本和许可证记录。
- [ ] 姓名和生日不写入 URL、不发送外部 API；反馈 JSON 只有用户主动下载。
- [ ] 键盘用户能完成输入、生成、下钻和分享；焦点边框清楚。
- [ ] 分享弹窗打开后焦点位于关闭按钮，关闭后焦点回到原按钮。
- [ ] 输入错误使用文字和 `role=alert`/状态提示，不只依赖颜色。

- [ ] 3–5 名真实用户完成核心任务并记录匿名反馈。
- [ ] 负责人或指定核验人确认立春分界、节气换月、日柱算法和二十八宿口径。
- [ ] Windows 安装包、代码签名和更新策略经过单独范围确认。
