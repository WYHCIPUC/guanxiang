# 基础计算模块规格（原型）

## 当前目标

当前计算使用近似节气边界、公历日序和天干地支五行映射，只用于验证界面、命纹和分享卡流程，不作为正式历法服务。

## 输入

- `name`：可为空的称呼。
- `dateValue`：`YYYY-MM-DD`格式的公历日期，范围1900-01-01至今天。

## 输出

- 年柱、月柱、日柱各一组干支。
- 五行五项分数和百分比。
- 最高分五行作为主色。
- 用输入哈希生成稳定命纹。

## 当前实现口径

- 年柱：以每年2月4日作为立春近似边界。
- 月柱：使用固定的节气近似日期表切换月支。
- 日柱：使用公历日对应的儒略日序推导干支日。
- 五行：统计三柱的天干和地支各一次，不加入季节旺衰权重。

## 资料核验结论

公开天文资料把节气定义为太阳黄经每15°的时刻，且具体时间受年份、时区和天文历算影响。香港天文台在2026-10-04复核的资料还说明，其节气时刻采用英国 HM Nautical Almanac Office 和美国 Naval Observatory 提供的天文数据，并以香港时间（UTC+8）发布。固定到某月某日的表格只能作为无精确历算时的降级体验，不能作为正式排盘依据。

正式版本应保存：年份、时区、节气名称、精确时间、资料来源和核验日期。

## 正式版替换前必须确认

- 立春还是春节作为年柱分界。
- 节气换月的具体规则。
- 日柱的历法算法和时区处理。
- 五行旺衰是否只计数，还是需要季节权重。
- 每个规则的来源、版本和测试样本。

## 禁止用途

结果不能用于健康、寿命、婚姻、投资、法律或其他现实决策建议。
