## 填写规则

1. 不要用项目负责人自己重复操作代替真实用户证据。
2. 不要把 `npm test`、Service Worker 模拟或 `desktop-check` 写成真实桌面窗口通过。
3. 用户记录只保留匿名编号、设备类型、完成时间和观察，不提交姓名、生日或联系方式。
4. 每次修改外部状态后重新运行 `npm run verify`，并在本表补充日期和证据。

## 允许的发布措辞

在所有外部门槛完成前，只能使用“Windows 桌面开发 Alpha”“第一阶段可运行原型”“小范围体验”或“网页预览”。不得使用“正式排盘”“预测服务”或暗示结果能指导现实决策的措辞。
