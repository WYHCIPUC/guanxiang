# 浏览器验收记录

## 环境

- 日期：2026-10-04
- 页面：项目自带 Node 静态服务器 `npm start`（`http://127.0.0.1:4173/`）；移动端修复曾用新端口 `http://127.0.0.1:4184/` 复测，避免浏览器缓存旧 CSS
- 工具：Codex In-app Browser（DOM/Playwright 观察）
- 测试输入：示例“知微 / 2000-01-01”，另测试只填生日的“观星者”路径

## 已验证

- 首页真实加载，标题、空盘、开始按钮和免责声明可见；浏览器运行时没有错误日志。
- 输入页可填写称呼和日期，提交后显示“知微的璇玑盘”；只填日期时显示“观星者的璇玑盘”。
- 命盘、五行、命纹、星官、生日节气和阴阳四维详情入口都能打开并返回总盘。
- 四维滑杆改为 82 后刷新，重新进入页面仍为 82，证明本地迁移/保存路径在真实浏览器中生效。
- 分享弹窗打开后焦点进入关闭按钮；按 Escape 关闭后焦点回到“生成分享卡”按钮。
- 点击 SVG 下载后，下载锚点立即出现并在约 1 秒后清理，符合 Blob URL 延迟释放设计。
- 复制分享摘要后按钮反馈“已复制摘要”。
- 输入页“返回首页”和空日期错误提示可用。
- 在 375px 移动视口下，重新生成总盘后，`scrollWidth = 360`、可视内容宽度 `clientWidth = 360`，总盘容器被限制在内容列内，没有横向溢出。
- 页面运行时错误日志为空。
- 使用 `npm start` 启动后的真实浏览器流程也已复测：首页、只填日期生成总盘和运行时错误日志均通过。
- 在说明页保存本地反馈后点击清除，页面显示“已清除本地观盘和反馈记录”，反馈下载入口随即提示“请先保存一份反馈”，证明观盘记录和反馈记录都会清除。
- 在 `npm start -- --port 4191` 的新实例中生成“品牌测试 / 2000-01-01”观盘，点击顶部品牌按钮返回首页后刷新，仍回到“品牌测试的璇玑盘”；证明品牌按钮只导航，不会误清除本地记录。
- `npm test` 另外通过了 Service Worker 行为模拟；这补强了代码级证据，但不替代真实浏览器断网验证。
- 新增可选命令 `npm run edge-offline-check`，用于在本机 Edge 中自动检查离线页面和非导航资源失败行为；当前 Codex 桌面环境的 Edge 未开放 DevTools Protocol，因此本次输出为 `UNVERIFIED`，不能计入离线通过。
- 在 `npm start -- --port 4195` 的当前版本中，浏览器可访问树把称呼和出生日期识别为有名称的文本框；生成“无障碍测试 / 2000-01-01”后，分享弹窗识别为 `dialog`，关闭按钮获得焦点，说明输入标签和弹窗语义与自动检查一致。
