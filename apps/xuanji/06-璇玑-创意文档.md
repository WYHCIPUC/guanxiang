# 璇玑 · 数字观象台
## 创意总案（项目初始文档）

- **版本** v0.1 ｜ **日期** 2026-10-03 ｜ **状态** 草案
- **项目定位**：传统文化 × 数据可视化的互动体验产品
- **一句话**：输入一个名字、一个生日，换回一座属于你的、可以旋转的宇宙。
- **项目名备选**：璇玑（主推）／观象台／知微 —— 下文统一用「璇玑」。
  「璇玑」既是北斗魁星之名，又是上古浑天仪之谓，天然契合"个人宇宙"的主概念。

---

## 1. 愿景与机会

三条基本判断：

1. **年轻人要的不是算命，是"认识自己"的入口。** MBTI、星座的流行证明了这一点——人们渴望一套有仪式感、可分享的自我叙事框架。
2. **中国传统术数是被严重低估的可视化题材。** 罗盘、紫微盘、六十四卦、二十八宿——结构规整、自带视觉基因、层层嵌套，却几乎没有像样的数字产品。现有产品要么是"输生日出一段话"的文字流，要么是专业排盘软件的密集盘面。
3. **中间地带是空的**：美的、可玩的、有文化考据的个人术数可视化体验。

璇玑要做的事：**不做算命工具，做观象体验。** 把术数当作一套古老的"数据语言"来翻译，而不是当作预言来卖。

## 2. 创意内核

### 2.1 主概念：璇玑总盘

全站即一座**数字璇玑盘**——借鉴罗盘、浑天仪与三垣二十八宿的环形结构，用户的出生数据不是被"查询"的，而是被"安放"在盘面的环上。

盘面从内到外四层：

| 环层 | 内容 | 用户数据落点 |
|---|---|---|
| **心环** | 太极阴阳鱼 + 五行雷达 + 命纹印章 | 五行分布、命纹 |
| **中环** | 八卦 + 十二地支（时辰） | 年支、月支、日支三枚"盘钉" |
| **外环** | 二十八宿 + 二十四节气 | 本命星官、生日节气 |
| **缘环**（双人模式点亮） | 合婚对照环 | 对方属相、对方星官 |

交互核心：**盘可旋转**（拖拽惯性转动，环与环可差速），盘钉即入口——点击任意盘钉下钻进入对应模块；每个模块的结论最终回到总盘"点亮"一处（星官亮起、环描金、雷达补形）。**总盘即是首页、导航、进度面板与最终成果**。

空盘状态：用户未输入时，空环缓缓自转，盘心一行字——「落座，报上名来。」

### 2.2 核心创意一：命纹 —— 由出生数据生成的个人图腾

以「姓名 + 生日 + 性别」做确定性散列种子（同名同生日者纹样相同，保证"命纹"的宿命感），用生成式图形算法绘制一枚**印章式个人图腾**：

- 纹样语汇取自云纹、卦爻线、星点连线，五行占比决定各元素的密度与配色权重；
- 五行偏旺者纹样舒张，偏弱者收敛——**图腾的形态本身就是命局的可视化**；
- 命纹出现在：总盘心环、个人分享卡、页眉水印。

类比：它是你的"数据指纹"，但语言是篆刻与云纹，而不是二维码。

### 2.3 核心创意二：五行色引擎 —— 一人一色

全站界面主题色不是设计定死的，而是**由用户命局五行分布实时生成**：

- 五行对应五色系（青／赤／黄／白／黑），界面主色、点缀色、命纹色均按五行占比加权混合；
- 五行偏木者满目青碧，偏火者朱调，平和者近于沉黄——**界面本身成为命理结论**；
- 这是全站最强的"哇"点与分享动机：两个人打开同一个产品，看到的是两种颜色的璇玑。

配套**五音引擎**：宫商角徵羽对应土火金木水，交互音效（转盘摩挲、结论揭示的磬声）按用户五行调律偏重。多感官一致性。

### 2.4 核心创意三：阴阳四维 —— 把 MBTI 译回阴阳话语

MBTI 不以"西方测评"的面目出现，而是被重新表述为**四对阴阳的权衡**：

| MBTI 维度 | 阴阳话语 | 滑条两端 |
|---|---|---|
| E – I | 动与静 | 阳动（外散）↔ 阴静（内守） |
| S – N | 形与神 | 观形（实感）↔ 驭神（直觉） |
| T – F | 理与情 | 依理 ↔ 任情 |
| J – P | 行与化 | 循行（有序）↔ 随化（自流） |

用户拖动四条"阴阳鱼"滑条（百分比连续可调），四维均衡度即时换算为**土性**（土主中和）——四组气质 NT／NF／SJ／SP 对应水／木／金／火，加上均衡度之土，正好合成一枚**性格五行雷达**。测试过程本身就是一次太极推手式的交互。

## 3. 设计原则（五条）

1. **一切皆盘** —— 所有信息长在环上，所有导航就是转动盘面。
2. **少即是玄** —— 核心输入只有：姓名、出生年月日、性别（+时辰选填、MBTI 四滑条）。
3. **一人一色** —— 五行色引擎驱动，拒绝千篇一律的默认主题。
4. **有典可查** —— 每个结论可展开"出处"注脚（《灵枢》《协纪辨方书》等），玩得起也要考据得起。
5. **信而不迷** —— 文案玩味而不恐吓，娱乐而不越界，页脚常驻免责声明。

## 4. 用户旅程

```
入（报生辰）→ 排（璇玑成盘）→ 观（总盘总览）→ 玩（逐环下钻）→ 铭（命纹与分享）
```

1. **入**：一屏极简输入——姓名、公历生日（可切农历）、性别、时辰（选填）、四条阴阳滑条。全程不超过一分钟，支持"先跳过性格测试"。
2. **排**：点击「观盘」，总盘从中心涟漪般逐环生成：太极生两仪、五行雷达成形、盘钉逐枚落下、星官亮起——**排盘过程本身是一场 3–5 秒的仪式动画**。
3. **观**：全景总盘，一眼看到自己的三枚支钉、本命星官、五行形态与主色。
4. **玩**：点盘钉下钻六大殿（见 §5），每个模块独立成页、独立成图。
5. **铭**：生成命纹印章与分享卡（见 §6.7），存档于本地。

## 6. 分模块详设

### 6.1 六字命盘 【命】
- **计算**：公历 → 干支历（年柱以立春换年、以节换月、日柱按历法直推）。无时辰即三柱六字。
- **视觉**：六枚大字干支印章横陈，**第四柱以虚线空章呈现**——「时辰未知，虚位以待」，把数据缺口做成视觉叙事而非遗憾。
- **文案示例**：`甲子 · 丙寅 · 戊午 —— 你的天地有六字。第六字尚缺，虚位以待一场黎明或黄昏。`

### 6.2 五行气象 【命】
- **计算**：六字（或八字）五行计数 → 旺衰分布。
- **视觉**：中央五行雷达，外围用"气候意象"隐喻——木旺如春林、火旺如长夏、水旺如夜雨……由分布参数化生成一幅小景。
- **文案示例**：`你的命局，春多木火，是一座少雨的南方山谷。`

### 6.3 生肖 · 纳音 · 太岁 【命】
- **计算**：年支定生肖；六十甲子查纳音年命（如庚午·路旁土）；年支逢流年太岁相冲即提示。
- **视觉**：生肖剪纸风本命卡 + 纳音"一卷土/一捧金"的物质意象图。
- **注意**：生肖分界默认立春，设置中提供"春节派"开关（见 §12）。

### 6.4 大运长卷 【命】
- **计算**：月柱起大运，阳年男顺／女逆、阴年相反；起运数 = 距节天数 ÷ 3（时辰缺失误差可忽略，三柱即可排大运）。
- **视觉**：**横向山水长卷**——每十年一座山，山色按大运干支五行着色，当前位置立一叶小舟，可拖卷浏览一生。这是全站最具"作品感"的一屏。

### 6.5 五格印 【名】
- **计算**：姓名按康熙笔画起天、人、地、外、总五格，查八十一数理；天人地定三才。
- **视觉**：五枚印章按九宫布局钤在一张"名帖"上，数理吉凶以墨色浓淡与描金表示，不做红黑恫吓。

### 6.6 本命星官（二十八宿）【星】
- **计算**：生日对照二十八宿（口径见 §12 开放问题），定位所属四象（青龙／白虎／朱雀／玄武）。
- **视觉**：一幅可拖动的四象星图，你的本命宿连线亮起，配星官卡（宿名、动物、吉凶属性、意象短文）。
- **文案示例**：`生于昴宿，西方白虎第七宿，形如鬃发，主分明。`

### 6.7 阴阳四维 + 二十五人古今对照 【性】
- **阴阳四维**：§2.4 的四滑条，判出 MBTI 类型，但页面通篇只讲"动静形神、理情行化"，MBTI 四字母作为小字注记（照顾分享语境的可识读性）。
- **古今对照**：左栏现代四维结果，右栏《灵枢·阴阳二十五人》对应"形人"描述（五形 × 五音亚型，亚型按次强维判定，细则待考据）。中西两套性格观同屏互文，是全站文化浓度的顶点。
- **天性·心性雷达**：命理五行（出生数据推得）与性格五行（滑条推得）双多边形同轴叠加——「天生的你」与「测出来的你」差多大，一眼即见。这是本产品独有的交叉洞察。

### 6.8 属相合婚 【缘】
- **计算**：双方年支查六合、三合、六冲、六害、相刑。
- **视觉**：双盘模式——两人的小璇玑盘旋转至特定角度**咬合成双鱼**；结果不分"宜/不宜"，只讲关系动力学（互补／共振／互为镜子）。

### 6.9 称骨秤 【玩】
- **计算**：袁天罡称骨歌，农历年月日时各查骨重加总（需公历转农历；时辰缺则标"缺时骨"，按六项出具并注明）。
- **视觉**：一杆**会摆动的杆秤**——年月日时的骨重化作秤砣逐个落上，秤杆找平，总重揭出诗诀卷轴。把"算命"翻译成一次称重的物理动画，是玩趣担当。

### 6.10 命纹与分享卡 【全局】
- **命纹**：见 §2.2。确定性生成（mulberry32 种子 = hash(姓名|生日|性别)），SVG/Canvas 绘制。
- **分享卡**：一屏纵排——命纹印章、主色渐变条、六字干支、本命星官、一句判语、站点水印。Canvas 导出 PNG，这就是产品的传播载体。

## 7. 视觉语言

- **双模式**：玄青夜景（墨底金线，主推，"夜观星象"）／宣纸日景（纸底墨字）。
- **五行色系**（建议值，待定稿）：

  | 行 | 色 | 参考色值 |
  |---|---|---|
  | 木 | 青 | `#2E6E55` |
  | 火 | 赤 | `#B5382F` |
  | 土 | 黄 | `#C9A050` |
  | 金 | 白 | `#E5E1D8` |
  | 水 | 黑 | `#1F2A33` |
  | 点缀 | 金箔 | `#D4AF37` |

- **字体**：标题用宋体大字／霞鹜文楷，印章用篆书，正文用细黑体；干支大字是版面主角，敢用 96px 以上的字。
- **纹样与图标**：白描线描（铁线描），云纹、卦爻线、星点连线三类母题贯穿。
- **动效**：缓动如毛笔提按（600ms 起），卷轴横向展开、盘面惯性差速旋转、结论揭示配磬声涟漪。尊重 `prefers-reduced-motion`。

## 8. 文案与内容原则

- **半文半白**：判语如`少木，遇春则荣`，不用白话啰嗦，也不用真古文晦涩。
- **断语软化**：无"凶灾"字眼，凶象一律转为"宜慎／宜养"的建设性表达。
- **每图必有注**：模块页脚一行出处（如`形色之辨，出《黄帝内经·灵枢》`）。
- **常驻免责**：`传统术数为文化演绎，仅供文化体验与娱乐，不构成任何人生建议。`

### 伦理与边界
- 不涉疾病、寿夭、婚丧吉凶的具断言；不做付费"改运"暗示；
- 数据纯本地（localStorage），无账号、无上传；
- MBTI 等现代工具在站点内明确标注为"现代对照物"，不与传统术数混同为真。

## 9. 技术方案

- **形态**：纯前端 SPA，无后端、无账号。
- **栈**：Vite + React + TypeScript；SVG 为主渲染（盘面、雷达、长卷），Canvas 负责命纹生成与分享卡导出；Web Audio API 做五音音效。
- **历法内核**：tyme4ts 或 lunar-javascript（干支、节气、农历、纳音现成），自封装 `PaiPanService`（三柱/四柱、五行计数、大运、称骨、五格五个纯函数模块，全部可单测）。
- **确定性生成**：mulberry32 PRNG，种子 = 字符串 hash(姓名|生日|性别)，保证命纹与配色可复现。
- **目录草案**：
  ```
  src/
    core/        # 历法与排盘纯函数（无 UI 依赖）
    pan/         # 璇玑总盘（SVG 交互）
    modules/     # 六殿各模块页
    engine/      # 命纹生成 / 五行色引擎 / 五音引擎
    share/       # 分享卡导出
  ```
- **性能与可及性**：SVG 按环懒渲染；全部交互可键盘可达；对比度按 WCAG AA。

## 11. 考据与数据附录

**需内置的数据表**：六十甲子纳音表、二十八宿对照表（含四象归属与动物）、称骨歌权重及诗诀、八十一数理吉凶表、康熙笔画字库、《灵枢》二十五人特征摘编、节气意象文案库。

**开放问题（需定口径）**：
1. **生肖/年柱分界**：立春 vs 春节——默认立春派，设置提供开关；
2. **二十八宿生日口径**：农历轮值法与民间公历对照表不一致——先采用流传最广的公历表，页脚标注口径，后续考据切换；
3. **姓名笔画**：默认康熙笔画（五格法正宗），提供简体笔画开关；
4. **二十五人亚型判定**：《灵枢》原文五音亚型缺乏现代判定规则——首版按"次强性格维"判定，标注为产品化演绎；
5. **时辰缺失措辞**：统一话术「虚位以待」，严禁默认午时冒充已知。

**参考典籍**：《周易》《黄帝内经·灵枢》《滴天髓》《三命通会》《协纪辨方书》《袁天罡称骨歌》。
