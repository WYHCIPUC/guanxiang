# 更新记录

## 0.3.0 · Windows 桌面客户端 Alpha

- 将 Windows 优先桌面客户端确定为主要产品形态，网页版本调整为开发预览和备用体验。
- 新增 Electron 主进程、固定 `xuanji://` 本地协议、窗口安全配置和空预加载脚本。
- 增加桌面壳静态检查、桌面客户端方案、桌面发布与验收文档。
- 桌面端不注册网页 Service Worker，不加载远程脚本，不开放外部导航或未审查的新窗口。
- 新增“今日观象—观象日志—七日复盘”本地使用闭环，支持 JSON 导入、导出和按日期删除记录。
- 记录增加场景、事实、感受和下一步字段；日志支持导入预览确认、删除后短时撤销，以及两条记录的并排对照。
- 将五行从一次性结果改为可选择的行动镜头：启动、表达、承接、收束、沉淀。
- 七日复盘增加连续记录天数，空日志导出会给出明确提示。
- 统一路线图、发布说明、测试清单、外部门槛和完成审计的桌面口径。

## 0.2.2 · 审计修正与发布稳固

- 修复阴阳四维刷新后丢失的问题，并限制本地迁移数据范围。
- 将入口、Service Worker和manifest改为适合相对路径部署的写法。
- 修复SVG/JSON下载的Blob URL过早释放问题。
- 修复亚洲时区午夜附近日期上限可能落后一天的问题。
- 为分享模态补充Escape关闭、焦点陷阱、焦点恢复和复制状态播报。
- 将离线失败回退限制为导航请求，避免把HTML错误返回给脚本或样式请求。
- 增加HTTP资源检查，发布检查扩展为10项。
- 增加不依赖第三方包的 Node 内置本地静态服务器，Windows启动脚本优先使用它并保留 Python 备用方式。
- 修复“清除本地观盘记录”未同步删除本地反馈的问题，并增加清除结果提示和自动检查。
- 增加 Service Worker 行为模拟检查，覆盖缓存安装、导航回退和非导航错误保留。
- 增加 `npm run verify` 一键串联构建、方案、核心、发布和 HTTP 检查。
- 复核香港天文台公开节气资料，并将复核日期、数据来源与近似口径限制写入来源和算法文档。
- 新增外部验收运行手册，明确电脑、手机、离线和真实用户试用的执行步骤与通过条件。
- 新增可选 Edge 离线验收脚本，自动检查 Service Worker 控制、离线刷新和缺失脚本的失败边界；无法启动浏览器时明确输出未验证。
- 新增外部发布门槛状态表，区分项目侧已通过证据与等待真实用户、设备或负责人确认的项目。
- 为表单标签、分享弹窗语义和 `prefers-reduced-motion` 增加自动验收检查，烟测扩展到 36 项。
- 同步更新第一阶段验收文档，明确 Node 启动优先级、36 项烟测和 Edge 离线检查命令。
- 登记首轮试用的临时默认范围，明确它等待负责人确认，不扩大当前 MVP 授权。
- 修复顶部品牌按钮误绑定“重新开始”动作的问题；现在品牌按钮只返回首页，清除记录仍需点击明确的“重新开始”。
- 新增十四部分整体方案、真实浏览器验收记录和静态构建/方案完整性检查。
