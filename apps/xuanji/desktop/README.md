# 璇玑桌面壳（开发 Alpha）

桌面客户端是项目的主要产品形态。这里的 Electron 壳已经完成窗口、安全配置和本地资源协议，并已把 Electron 开发依赖记录到项目；尚未生成安装包。

## 当前状态

- Windows 优先，单窗口，默认 1100×760，最小 860×640。
- 页面通过固定的 `xuanji://bundle/` 本地 origin 加载，避免随机端口导致本地存储路径变化。
- `nodeIntegration` 关闭、`contextIsolation` 开启、渲染器启用沙箱。
- 不加载远程脚本，不允许外部页面在应用窗口内导航，不暴露文件系统或 Shell API。
- 桌面离线不依赖 Service Worker；资源随桌面包提供。

## 启动开发窗口

在项目目录运行：

```powershell
npm install
npm run desktop:dev
```

第一次安装会下载较大的开发依赖；依赖已经存在时可直接运行 `npm run desktop:dev`。当前网页预览仍使用根目录的 `npm start`。

## 通过条件

开发窗口能在无网络时打开首页；窗口没有地址栏；输入、今日记录、日志、七日复盘、底色详情、SVG 下载和打印可用；关闭后没有本项目遗留的 Node 服务进程；刷新或重开后本地观盘和日志仍在。

## 还没有做

安装包、代码签名、自动更新、托盘、账号、云同步、原生文件夹写入和远程日志都不在当前 Alpha 范围内。
